I'm a software engineer in San Jose, CA. I build warehouse automation software at Dematic and AI systems at [AI4Everyone](https://ai4everyone.dev), a startup I co-founded. Most of that work lives in AI4Everyone's private repositories.

### Factory · private

A cloud platform where a team of AI agents does software work under human control.

- A lead agent breaks a job into small tasks and hands them to coder, researcher, writer and reviewer agents.
- Each agent works in its own disposable container. Code changes come back as pull requests, checked by a separate reviewer agent. Nothing merges without human approval.
- Runs survive crashes and resume from saved state. Cost tracking, budgets and an immutable audit log are built in.
- It's operated from Claude Code or Codex through an MCP server, or from a web dashboard.
- Built with TypeScript, AWS (Lambda, ECS Fargate, API Gateway, RDS PostgreSQL, S3), Terraform, MCP and OpenTelemetry.
